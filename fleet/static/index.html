Connect a worker and understand its status
Enroll each worker locally with its owner’s approval. Follow the included remote-access guide, then add its exact Tailscale HTTPS desktop and status addresses to the controller’s workers.json. No API key is needed. Unconfigured tailnet devices remain visible with unknown desktop status.
Transport comes from Tailscale. Desktop means an active graphical session. App reports the ChatGPT process only; T3 Code and other agents are not monitored. Work remains unknown because there is no verified global job-status integration. An unavailable or old report never becomes “idle.”
Desktop links share the worker’s existing Xorg session. You still authenticate. A monitor or supported display adapter may be needed on physical machines; no virtual display is created.
